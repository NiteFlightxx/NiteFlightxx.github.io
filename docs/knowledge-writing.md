# 知识库内容边界与连续阅读约定

知识库按问题组织完整文档。文章之间可以有关联，正文理解过程应在当前页面闭合。当前基础梳理覆盖 43 篇公开文章，三个兼容重定向页面不作为新的知识主题。

## 正文的责任

- 定义本篇使用的输入、输出、符号、空间、单位和假设。
- 必要的前置概念在使用处给出最小回顾，并完成当前例子的计算。
- 不使用“先读另一篇”“推导在别处”替代当前论证中的必要步骤。
- 概念文章讲清来由与基础推导；应用文章简要固定约定，然后完整解决自己的问题。
- 源码文章保留具体版本、路径、调用链与行号。数学摘要不能冒充新的源码证据。
- 代码、公式与配图都应有明确用途，不按篇幅或卡片数量判断完整性。

## 主题归属

### 基础数学

- 微分基础：函数、导数、偏导数、梯度、约束极值、Jacobian 的定义与链式法则，连接弹簧的约束、能量和力。
- UE 空间数学：向量、空间、矩阵、FTransform、旋转和具体 API 约定。
- Jacobian：局部映射的准确性，约束速度与虚功对偶，奇异性、伪逆和 IK 逆问题。
- Hessian：二次模型、曲率、正定性、Newton 与近似曲率。
- 常微分方程：状态、初值、连续模型、时间尺度与事件。
- 数值积分：离散更新、误差、稳定域、能量行为与子步。
- 线性系统迭代：冻结线性问题的更新、残差、收敛与预条件。
- 偏微分方程：场、空间算子、边界、空间离散与具体格式的稳定性。
- 数学符号：含义、记号与 LaTeX 查阅；不是其他文章的必读前置。

### 物理模型与接触

- 物理总览：说明领域之间的关系，作为导航页保留正文主题入口。
- 质点动力学：状态、力、动量、功、能量和解析基准。
- 连续介质：运动映射、形变、应力、守恒和材料关系。
- 刚体动力学：质心、力矩、惯性、角动量与姿态演化。
- 可变形体：材料形变与恢复，体积、布料、杆及塑性状态。
- 流体动力学：平流、压力、黏性、不可压缩与边界。
- 多物理耦合：界面作用、反作用与时间排程。
- 经典力学：同一模型的牛顿、拉格朗日与哈密顿表述。
- 接触响应：撞击、持续支撑、摩擦、流形和缓存的因果链。
- 凸体碰撞：SAT、支撑映射、Minkowski 差、GJK 与 EPA 的几何推导。

### 求解方法

- 物理约束：允许方向、刚体约束行、有效质量、累计冲量与耦合迭代。
- PBD / XPBD：逐约束位置投影、柔度、累计乘子与几何约束。
- VBD / AVBD：离散目标、能量导数、局部块及增广与对偶机制。
- 四种方法对比：固定模型和预算，比较目标、更新块、误差、状态和成本；不再重写各算法全部约束实现。
- 弹性杆：材料标架、弯曲、扭转与离散约束。
- SPH：核插值、压力与黏性离散、边界、邻域和压力型求解路线。
- PBF：为当前密度约束就地定义核与梯度，展开位置修正与速度重建。
- JGS2：论文的子空间、共旋近似、预计算与并行弹性耦合。

### 实现与工程链

- 2D 物理引擎：把状态、碰撞、求解、缓存与提交放入同一次更新。
- avbd-demo3d：原生刚体 AVBD 数据结构、六自由度块与真实循环。
- three-avbd：WebGPU 阶段、缓冲、扫描、邻接、染色和状态提交。
- GPUPhysicsLab：从 Compute Shader 基础到 UE/RDG 宿主、具体求解与生命周期。
- Chaos 架构：刚体演化的状态分层、碰撞、岛、求解与回写。
- Chaos GJK：查询接口、空间、margin、输出有效性与退化状态。
- Chaos 运动学同步：目标与镜像的线程、状态和版本。
- Chaos Cloth：Dataflow 构建、材料参数与运行时约束的对应。
- Niagara：参数、模块、绑定与 GPU 数据接口。

### 动画与控制

- 动画节点：姿态与空间基础，以及不同节点的局部算法和执行契约。
- 全身 IK：FullBodyIK 与 PBIK 的实际求解、限位和集成。
- 预测落脚：候选生成、接触时机、支撑状态与目标规划。
- IK Retargeter：源到目标姿态的 Op 数据流、链映射与参数。
- Motion Matching：数据构建、查询、评分、选择、混合与最终姿态。
- 四旋翼交互：推力、姿态、平移、PID 与混控的直观因果关系。
- AircraftLab：插件串级控制、轨迹、MPCC、ORCA、分配与仿真所有权。

前置关系用于组织知识图谱，不代表读者必须跳转才能理解本篇。反向链接用于发现关联，默认折叠，不与正文的延伸链接重复铺开。

已有 URL 与章节锚点属于公共接口。删减重复章节时，在 knowledge-legacy-anchors.json 中映射到保留内容，并检查旧链接仍能定位。
