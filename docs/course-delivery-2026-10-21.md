# 课程化首批交付记录

> 历史记录：本文件描述的课程平台方案已被用户修订。当前采用有序文档库，不展示课程目标、练习验收、规划课节或完成打卡；以 `docs/course-authoring.md` 与 `src/data/reading-order.json` 为准。

## 已实现

三门课程、25 个单元、50 个课节规格，由同一份 JSON 驱动首页入口、课程目录、三个核心领域页与课文阅读器。每课包含目标、练习、先修关系与发布状态；仅 3 课有正文，其余 47 课明确显示规划中。原有 34 篇公开参考文章未覆盖，现有公开内容合计 37 篇。

三篇首课分别介绍点与位移、匀速时间步、骨骼父子空间，包含 LaTeX、手算、自检答案、参考资料和按需加载的 SVG 数值实验。课程完成记录独立保存，手动确认，不以滚动百分比替代掌握程度。

旧文章 URL、旧领域 URL 和专题锚点保留。旧收藏查询入口迁移到参考资料库；首页与侧栏不再把旧文章列表称为课程。未恢复 AVBD 交互视口，未引入后端。
