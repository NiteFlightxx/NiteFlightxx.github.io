# 知识库文档组织与写作

## 当前产品方向

2026-10-21 根据用户反馈修订：这是按基础到实现顺序组织的知识库，不是教学平台。取消课程介绍页、学习目标、练习验收、规划课节卡片与完成打卡。用户进入知识库即可看到正文，通过同一份侧栏目录选择其他文档。

## 文档顺序

- `src/data/reading-order.json`：公开文档的唯一阅读顺序，按领域、阶段和文档排列，不按发布日期排序。
- 当前 34 篇主文档均有明确位置；3 篇旧的微型文档只保留兼容跳转，不在树里重复堆叠。
- 没有正文的主题不出现在文档树中。旧课程大纲和 curriculum JSON 仅保留为历史写作素材，不驱动线上界面。
- 新增公开文档时，补充阅读位置；审计检查重复、缺失、草稿泄漏和顺序。
- 不声明现有长篇参考文档已经全部重写成从零入门的体系；内容难度仍需逐篇整理。

## 路由与阅读

`/knowledge/` 直接显示基础文档。文章保留原 URL；左侧是全库有序目录，中间正文，右侧本文目录。窄屏使用折叠的目录工具。上一篇/下一篇来自当前文档分组中的已发布内容，不指向不存在的规划页。

旧 `/knowledge/courses/:id/` 与领域 URL 显示对应首篇文档，保留兼容访问，但网站入口直接链接文章。所有别名使用原文章 canonical，并从 Pagefind 索引中排除，避免重复搜索结果。收藏与历史记录也使用原文章地址。

`/knowledge/library/` 用于全量搜索、筛选、收藏与最近阅读，不再区分“课程库”和“参考库”。

## 正文与交互

正文按概念、推导、例子、工程实现自然展开，不强制填写目标、考核或自检模板。数学统一使用 LaTeX；保留可操作的小图与数值演示，用于解释因果关系，而不是验收读者是否掌握。

源码说明继续注明文件、行号与快照，区分源码事实、工程建议和运行时验证。全库标题、摘要与导言已进入编辑优化；ODE、数值积分、经典力学、凸体碰撞和 Chaos GJK 是第一批整体重写的正文，其余技术章节仍需逐篇审校，不能把标题调整称为全库技术复核。标题与模板以 `docs/ADDING_ARTICLES.md` 为准，不再强制使用“详解 —”句式。

## 本地状态与验证

取消独立课程完成组件与状态读写代码；不主动删除已有浏览器数据。原收藏、最近阅读、字号和阅读进度继续使用，不将阅读进度解释为掌握程度。

执行 `npm run check`、`npm run audit:reading-order`、原有内容审计和 `npm run build`。构建检查保证文档树服务端可见、所有文章可达、别名不重复索引，且不再出现课程目标、练习验收与完成打卡界面。
