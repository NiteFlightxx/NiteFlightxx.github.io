# React Bits components

SideRays, BorderGlow, GooeyNav and Hyperspeed are adapted from the source supplied by the user from React Bits.

- License: MIT + Commons Clause; see react-bits-LICENSE.md in this directory.

Local adaptations include TypeScript types, site palette, bounded background rendering,
live reduced-motion preferences, passive pointer handling, and preserving the site's
native card links and buttons. These components are integrated into this website.

Hyperspeed uses the site's purple palette, transparent compositing with SideRays,
bounded rendering resolution, visibility suspension and context-loss handling.
Its Three.js WebGL renderer does not require WebGPU.
